Um técnico precisa verificar se há espaço suficiente para instalar um programa. Verifique se o espaço disponível no computador é suficiente para a instalação do programa.O usuário deve informar o espaço disponível e o espaço ocupado pelo progrma. Se houver espaço suficiente, exiba a mensagem "Instalação permitida". Caso contrário, exiba "Instalação não permitida".
