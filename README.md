# Estudos de JavaScript e Lógica de Programação

Registro contínuo do meu aprendizado em JavaScript e lógica de programação, reunindo conceitos, exemplos e exercícios práticos.

## Objetivo

Consolidar os fundamentos de lógica de programação por meio da prática e aprofundar progressivamente minha compreensão de JavaScript, buscando desenvolver maior autonomia na resolução de problemas e evoluir profissionalmente na área de tecnologia.

## Conteúdos e estrutura

O repositório é organizado de forma progressiva, acompanhando meu aprendizado e buscando integrar os diferentes conceitos estudados.

Atualmente, reúne conteúdos relacionados a:

- Tipos de dados e variáveis
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Arrays
- Funções
- Exercícios de lógica de programação

## Desenvolvimento

Este repositório está em constante atualização conforme avanço nos estudos.

Atualmente estou aprofundando meus conhecimentos em funções. Os próximos conteúdos incluem objetos, manipulação do DOM e outros conceitos da linguagem.
